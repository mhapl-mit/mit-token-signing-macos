Test podpisu kartou

Test vyzkouší celý podpis: výběr certifikátu, zadání PINu a podpis kartou. Podpis stránka nakonec ověří.

Jde jen o zkoušku. Podepisují se zkušební data, žádný skutečný dokument, a nic se nikam neodesílá. Načtení karty může trvat několik sekund, než se otevře okno.
