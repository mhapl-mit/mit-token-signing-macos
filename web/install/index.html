Podpis kartou v prohlížeči

Pro podpis čipovou kartou nebo tokenem potřebujete tyto čtyři věci. Stránka sama zjistí, co vám chybí.

  1. 1

    Prohlížeč Google Chrome nebo Microsoft Edge

    Zjišťuji…

    Podpis kartou funguje v prohlížečích Google Chrome a Microsoft Edge. Nainstalujte si jeden z nich a otevřete v něm tuto stránku znovu.

    Stáhnout Chrome Stáhnout Edge
  2. 2

    Rozšíření M.I.T. Consulting Token signing

    Zjišťuji…

    Otevřete obchod s rozšířeními, klikněte na Přidat do prohlížeče a potom tuto stránku obnovte.

    Otevřít obchod s rozšířeními

    V Edge se rozšíření instaluje z Internetového obchodu Chrome: v obchodě nahoře klikněte na Povolit rozšíření z jiných obchodů, potvrďte Povolit a pak klikněte na Získat.

    Máte-li v Edge starší rozšíření M.I.T. Consulting Token signing z obchodu Microsoft Edge, odeberte ho (edge://extensions → Odebrat), jinak by se podpis spouštěl dvakrát.

  3. 3

    Program MIT Token signing

    Zjišťuji…

    Program zprostředkuje rozšíření přístup ke kartě.

    Stáhnout program

    Otevřete stažený soubor a projděte instalaci. Pak klikněte na Zkontrolovat znovu.

    Otevřete stažený soubor a projděte instalaci. Pokud macOS hlásí, že soubor nelze otevřít, otevřete Nastavení systému → Soukromí a zabezpečení, dole klikněte na Přesto otevřít a zadejte heslo k Macu. Pak klikněte na Zkontrolovat znovu.

    Balíček je pro Ubuntu 22.04 a novější a Debian 12 a novější. Nainstalujte ho v terminálu:

    sudo apt install ~/Stažené/mit-token-signing_amd64.deb

    (V anglickém systému je složka ~/Downloads.)

    Pak klikněte na Zkontrolovat znovu.

  4. 4

    Software ke kartě

    Tento krok stránka ověřit neumí.

    Na počítači musí být program od vydavatele vaší karty nebo tokenu, se kterým karta už funguje:

    I.CA SecureStore · ProID+ (Monet+) · PostSignum

    Na Linuxu dále balíčky pcscd a pro karty bez programu výrobce opensc (instalace programu MIT Token signing je doinstaluje sama).

Vše potřebné je nainstalované, můžete podepisovat.
